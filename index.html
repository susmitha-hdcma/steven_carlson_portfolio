WaymarkHQ
Founder · Architect · Engineer




A governance control plane for AI coding agents: move at AI speed, keep production under control.


Waymark puts a trusted boundary between agent intent and privileged action: a native macOS Studio that runs agents in isolated workspaces with approvals, checks, and releases in one view, and a Broker that keeps credentials outside agent reach, enforces policy before execution, and keeps a durable evidence trail. Classic doctrine (least privilege, separation of duties, auditability) applied to agentic development.


ProblemAI agents get faster, but production does not get safer.
What I builtA native Studio plus a Broker that holds credentials and enforces policy first.
ResultPolicy checked before execution, with an evidence trail for every change.


AI SecurityCredential isolation, policy-before-execution, evidence trails for autonomous agents.
CI/CD GovernanceRelease checks, approval gates, isolated git worktrees, built-in recovery (RepoSeatbelt).
DevelopmentNative macOS app, git tooling, MCP integration.


AI Agent GovernanceLeast PrivilegePolicy EnforcementMCPDevSecOps
