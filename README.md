# Steven Carlson Cybersecurity Portfolio

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.
4. Keep the `assets` folder beside `index.html`.

## Experience photos
The `assets/experience-*.jpg` files are original AI-generated editorial visuals used to make the experience timeline more visual. They represent the work areas (AI engineering, cloud infrastructure, digital forensics, EMS, and aviation); they are not documentary photographs of Steven or his employers.

The portrait currently references the portrait URL on the portfolio website, so it needs an internet connection.
